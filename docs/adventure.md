## Meet the idea before the game

New concepts begin with a short visual introduction. Use **Next** at your own pace, or replay a scene. For fractions, begin with one whole, split it into equal parts, select some of them, and then connect the picture with the written fraction. A parent can guide the activity. **Show me the idea** reopens an explanation whenever it is useful. Teaching is silent, with no voice narration. Viewing an introduction records only that it was viewed; it does not award coins or certify understanding.

When an adventure asks for a typed fraction, equivalent forms are welcome: `1 1/4`, `5/4`, and `1.25` all name the same value. Quarter-inch questions and diagram labels use fractions so decimal conversion is not a hidden prerequisite.

See [the learning-access design notes](learning-access.md) for the everyday choices supporting focus and reading comfort.

## Build division with rows

Grade 3 division activities do not require a typed numerical answer. Use **Add a row** or **Take away a row** when finding the number of groups. When finding an equal share, add or remove one item in every row together. The picture shows the row count, items in each row, and live total. Known quantities stay fixed for that question, so the experiment keeps its meaning.

Compare **your build** with the required total, then check it. Some problems ask for a picture-based choice. Missing-total problems calculate the answer from the rows you built. Changing the model does not submit an answer, and a wrong check keeps the work available to adjust. Pausing saves the current build in this browser.

## The learning loop

1. Pick one mission. Meet the idea first, then look at its challenge.
2. Change the model. Notice what changes and what stays the same.
3. Check your build or answer. Feedback explains the mathematical relationship.
4. Use a hint or worked help whenever useful. Supported practice is still practice.
5. Try the next challenge, then come back another day with fresh examples.

Missions use a small set of authored variations; replay does not generate unlimited new curriculum. A completion stamp records that the short practice sequence was completed. It does not certify mastery or record a school grade. No points depend on speed, and mistakes do not remove access to learning.

The collection starts with a free pet, habitat, case, and keychain charm plus 20 pretend coins. A different completed mission earns 15 coins once. The first correct practice check in each of the original 80 library lessons earns 5 coins once. Replaying the same mission or check remains available without repeatedly awarding the first-completion coins.

Open **My pets** or **My collection** to preview items and spend earned coins on more companions, habitats, cases, keychain charms, or imaginary food. Non-consumable items can be equipped after purchase; food is used from the care view. All purchases use pretend coins. There is no checkout, advertising, real payment, subscription, or random paid reward.

Pets remain safe and available when a learner takes a break. No pet gets sick, dies, or disappears through inactivity. Food is a playful interaction, not an obligation. Collection displays and celebration can be hidden.

## Saved progress and shared devices

Mission position, local completion stamps, pretend coins, collection inventory, and presentation choices use browser storage at this site address. They do not sync between devices or profiles. If storage is restricted, the experience works for the current visit and tells you saving is unavailable. Clearing site data removes the saved collection and progress. A downloaded file and the public website may have separate storage.

This edition has one local journey per browser profile. It has no student accounts, teacher dashboard, class roster, grades service, or application analytics. Use separate browser profiles if family members want separate collections. Do not enter personal student information in public feedback.
