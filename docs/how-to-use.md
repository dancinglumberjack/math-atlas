# Learn with Math Atlas

Math Atlas works best when you make a prediction, change one thing, and explain what you notice. There is no timer and no required account.

[Open the library](https://dancinglumberjack.github.io/math-atlas/#library) · [Back to the project](../README.md)

## Find a useful starting point

Search for the idea you are studying, such as **fractions**, **slope**, or **sine**. Collection filters group related lessons. **Find my starting point** opens the number-sense collection; it does not measure a student's level.

Open a lesson and read its goal. **Helpful to know** names prerequisite ideas, and selected lessons link to earlier lessons you can revisit. A glossary explains selected mathematical terms.

If an explanation feels too advanced, start with a prerequisite. You can move between collections without finishing them in order.

## Explore, explain, then practice

1. **Predict.** Before moving a control, say what you think will happen.
2. **Explore.** Change one control and compare the picture, measurements, and relationship. Use **Reset** to return to the original example.
3. **Explain.** Read **Why it works**, then choose **Show the next step**. Try explaining a step in your own words before revealing another.
4. **Try it yourself.** Switch to the practice tab. Enter a number, a fraction such as `3/4`, or scientific notation such as `3e-5`. Follow the displayed rounding guidance.
5. **Use support.** Ask for a hint or choose **See the reasoning**. After repeated incorrect attempts, feedback breaks the idea down further.
6. **Vary the example.** Choose **New challenge** and explain whether the same method still works. A new challenge changes values within that lesson's supported model.

A **Practiced** mark records one correct check in that browser. It does not prove mastery. Try several examples, explain your method, and apply it in a new setting to build understanding.

## Example: a box is made of layers

Open [Rectangular prism volume](https://dancinglumberjack.github.io/math-atlas/#lesson/rectangular-prism). Try length 4, width 3, and height 2.

- One layer has `4 × 3 = 12` unit cubes.
- Two unit-height layers contain `12 × 2 = 24` unit cubes.
- Turn on the separated-layer view to see the layers. The display gaps help you see them; the gaps add no volume.
- Increase the height by one. Predict how many cubes are added, then compare the result.
- Switch between the isometric and flat views and use the enlarge control to inspect the diagram.

Six lessons have these isometric views: scale drawings, rectangular prism volume, surface area, cylinder volume, cone volume, and sphere volume. Other lessons use the diagram that fits their idea.

## Bring an equation from school

The home-page helper accepts an equation of the form **`ax + b = c`**:

- `a` is an integer from **1 through 6**.
- `b` is an integer from **−6 through 6**.
- `c` is an integer from **−20 through 30**.

For example, type `3x + 4 = 16`, choose **Help me solve it**, then work through the linked lesson. `2x - 3 = 9` and `x = 5` also fit the supported form.

This entry does not solve arbitrary expressions, equations with variables on both sides, word problems, or uploaded photos. For another topic, select a lesson and explore its controls.

## Use the scientific calculator

Open **Scientific calculator** in the header or within practice. Type an expression or use its keypad, then press **Enter** or **Calculate**.

| To calculate | Type | Result or meaning |
| --- | --- | --- |
| Fractions | `3/4 + 1/2` | `1.25` |
| Powers | `2^3` | `8` |
| Square roots | `sqrt(49)` | `7` |
| Sine in degrees | `sin(30)` with DEG | `0.5` |
| Sine in radians | `sin(pi/2)` with RAD | `1` |
| Base-ten logarithm | `log(100)` | `2` |
| Natural logarithm | `ln(e)` | `1` |
| Previous result | `ans * 2` | Twice the last successful result |
| Percent | `50%` | `0.5`; percent always divides by 100 |

Functions need parentheses. Inverse sine, cosine, and tangent use `asin`, `acos`, and `atan`; they return angles in the selected mode. Factorial accepts whole numbers from 0 to 170. The calculator uses real-number arithmetic and reports unsupported or undefined operations.

Use parentheses to make grouping clear. For example, `6/(2*(1+2))` and `(6/2)*(1+2)` intentionally give different results. `200 + 10%` means `200 + 0.1`, not a ten-percent increase; use `200 * (1 + 10%)` for that.

The last five successful calculations appear in **Recent calculations** and reset on a page reload. When practice is open, **Use in practice answer** copies a successful result into the answer field; you still choose **Check**.

## Make reading more comfortable

Open **Reading support**. Choose a starting preset, then change individual settings until they suit you:

- **Dyslexia reading support:** a clear sans-serif typeface, larger text, and extra spacing.
- **ADHD focus support:** a simpler layout, one worked step at a time, and reduced motion.
- **Custom choices:** typeface, text size, line/letter/word spacing, background, stronger contrast, a reading guide, and motion settings.

These labels describe presentation options, not a diagnosis or guaranteed benefit. A student can use either preset or any combination of settings.

With the reading guide enabled, move your pointer to place the guide over a line. **Alt + ↑ / ↓** also moves it. **Listen to this step** uses the browser's speech feature when available. Pronunciation of mathematical notation may vary, so refer to the written equation alongside it.

Use **Reset to standard** to restore the original presentation. Choices are remembered in the same browser when storage is available.

## Saved work and privacy

Progress and the last lesson position stay in the browser and site address where you used them. A different device, browser profile, downloaded copy, or host address has separate storage. There is no account sync, class dashboard, or teacher gradebook.

**About the library** includes a control to clear practice progress. Clearing all site data also removes saved settings and lesson position. Private browsing and some school settings may block persistence. The lessons still run when saving is unavailable.

On a shared device, the next person using the same browser profile can see its saved state. Do not enter identifying information in public feedback.

## For families and teachers

Ask a student to explain a prediction before moving a control, then describe the evidence afterward. Use the visual as a conversation starter alongside schoolwork. A correct numeric answer alone does not show whether a student understands why a method works.

The library covers major topics but is not a complete, certified standards-aligned course. **About the library** and the [roadmap](roadmap.md) describe coverage gaps. Please share confusing steps or useful classroom examples through [the issue templates](https://github.com/dancinglumberjack/math-atlas/issues/new/choose), using anonymous sample problems.

## If something does not work

- **The hosted link is unavailable:** GitHub Pages may still need enabling or deploying. A downloaded `index.html` can be opened directly in a modern browser.
- **A typed equation is rejected:** check the supported form and integer ranges above.
- **A practice answer is rejected:** follow the rounding guidance and enter a number or simple fraction. Use the calculator for expressions such as `sqrt(2)`, then copy its numeric result.
- **Read aloud is unavailable:** try the device's browser speech support or use the written steps; speech is optional.
- **Progress disappeared:** check that you are using the same browser profile and address and have not cleared site storage.
- **A display or calculation looks wrong:** [report a problem](https://github.com/dancinglumberjack/math-atlas/issues/new/choose) with the lesson, control values, browser, and reproduction steps. Crop screenshots to remove personal information.
